# Cloan Home Decor — demonstração GitHub Pages

Esta é uma **versão estática de demonstração**. Produtos e preços são fictícios. A loja mostra o visual, filtros, busca, detalhes, sacola, alternância de tema e busca de CEP via ViaCEP. O envio de pedidos reais está bloqueado nesta demonstração.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `cloan-home-decor-demo`).
2. Faça upload **dos arquivos dentro desta pasta**, mantendo `index.html`, `demo-admin.html` e a pasta `assets` na raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`. Salve.
4. Abra o endereço informado pelo GitHub Pages após a publicação.

## Limitações

O GitHub Pages **não executa PHP nem MySQL**. O painel administrativo, login, cadastro de produtos, controle de estoque e pedidos reais precisam de hospedagem PHP/MySQL ou XAMPP. Esta demonstração não tem login real. O estoque e preços são fictícios.
